languages

Python is my primary language for platform and backend work - FastAPI for APIs, SQLAlchemy for data access, and general scripting for automation. I also have years of experience with TypeScript/JavaScript, Java/Kotlin, and have worked with Golang professionally.

infrastructure

Terraform is my go-to for infrastructure as code - I've built multi-environment platforms on both AWS and GCP with reusable module patterns. Kubernetes for container orchestration, with Helm for packaging and ArgoCD for GitOps deployments. I design infrastructure with clear boundaries between foundation, shared services, and application-specific resources.

ci/cd & automation

Very familiar with Buildkite, Argo, GitHub Actions, GitLab CI. Also familiar with Harness CI, but against my will. I've worked extensively with Jenkins, Spinnaker, and GoCD at enterprise scale. Strong believer in GitOps - infrastructure state, application config, and secrets all tracked in Git with automated sync to clusters.

data platforms

I design domain-driven data platforms with clear ownership boundaries. PostgreSQL for relational data, with per-domain schemas and bilateral API contracts. Experience with edge architectures - write buffering and read caching for offline operation with cloud sync. Focus on reducing coupling between domains so teams can evolve independently.

testing

Test-first mentality is a cornerstone of my practice. pytest for Python, Vitest/Jest for JavaScript, JUnit for Java. I've also spent a lot of time with Selenium and Cypress, but my favorite tool for browser automation is Playwright.

client-side

I've loved working with React since it converted this aspiring backend engineer into a V8 lover in 2016. Though I find React's own Context API and Zustand suitable and pleasant to work with in most circumstances, I maintain a high opinion of Redux and it's my personal choice for medium to large scale projects (though I admittedly think about stuff like this a lot less than I used to before AI made it easier to migrate back and forth). On the ZUUT project, I liked using Konva for smooth drag and drop interactions and animations.

backend & apis

FastAPI is my framework of choice for Python APIs - type hints, automatic OpenAPI docs, async support. I've also built platforms with Kotlin/Spring Boot and have deep experience with Java/Spring from my time on the Cloud Infrastructure team at GrubHub, where I worked on platform frameworks, API gateways, and service mesh architecture.

I focus on developer experience - CLI tools to scaffold new services, client libraries in multiple languages, safe self-service so engineers can create resources without impacting others.

observability

OpenTelemetry for distributed tracing - browser to database with a single trace ID. Experience instrumenting both frontend applications and backend services for end-to-end request tracing.
