Hi! I'm Luke. I'm a platform engineer focused on data platforms, infrastructure, and developer experience.

With over a decade of experience building systems at enterprise scale, I've spent the last few years working as an independent consultant on platform engineering engagements.

I build the platforms that product teams build on.

That means designing domain-driven data architectures, building infrastructure as code, creating CI/CD pipelines, and making sure engineers can ship with confidence.

I'm currently building an agentic infrastructure platform: a platform in a box that takes applications from source code to production, with an AI engineering agent that responds to alerts and prepares fixes. Previously, I built the platform behind a large enterprise's gamification product, which served 5.8 million requests at 99.986% success in its launch week, and led the architecture of a data platform for an autonomous robotics company. Python, Terraform, Kubernetes, AWS, GCP, Docker, PostgreSQL, GitHub Actions
